# Наши игры

Работаем здесь, на GitHub. Каждый пуш в `main` сам копируется на GitVerse
(`.github/workflows/gitverse-mirror.yml`), и людям даём ссылки GitVerse:

| Игра | Ссылка |
|---|---|
| Все игры | `https://<логин>.gitverse.site/test-repo/` |
| SCP: Побег | `https://<логин>.gitverse.site/test-repo/scp/` |
| Операторы дронов | `https://<логин>.gitverse.site/test-repo/fpv/` |
| Лес | `https://<логин>.gitverse.site/test-repo/les/` |
| Муха | `https://<логин>.gitverse.site/test-repo/muha/` |

Старые адреса `glebbelov85-tech.github.io/test-repo/...` перенаправляют на GitVerse
(`.github/workflows/github-pages-redirect.yml`), когда задана переменная `GITVERSE_PAGES_URL`.
