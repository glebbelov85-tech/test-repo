# Пульт кинофильтров (pult.js): как встроить в редактор

Отдельный блок со слоями (Стиль, Атмосфера, Свет, Цвет), вкладками библиотеки и плёнкой. Тот же, что в пробе.
Ничего, кроме `shader.js` и `filtry.js`, не требует. Стили вставляет сам (классы `kp-*`, корень `.kpult`).

## Подключение

```html
<script src="engine/filtry/shader.js"></script>
<script src="engine/filtry/filtry.js"></script>
<script src="engine/filtry/pult.js"></script>
```

```js
const pult = new KinoPult(panelEl, {
  filtry: F,                          // Filtry предпросмотра (null: пульт только ведёт состояние)
  onChange: (state, why) => {         // любое изменение; why: 'look','style','atmos','light','grade' или имя ползунка
    // записать state в выбранный отрезок / событие
  },
});
```

Блок занимает всю высоту `panelEl` (дайте ему высоту, например grid-ячейку). Прокручивается только библиотека,
поэтому видео рядом не меняет размер при смене вкладок. Для низкой панели: `pult.el.classList.add('compact')`
(прячет ползунки выключенных слоёв). Цвета переопределяются переменными `--panel, --well, --line, --line2, --ink, --mute, --acc`.

## Состояние = формат сцены

`pult.get()` отдаёт полное состояние, которое движок понимает в отрезке, событии и варианте выбора:

```json
{ "filter": "neon", "filter2": "eho", "mix": 0.3, "trans": "pyatna",
  "atmos": ["sneg", "tuman"], "atmosAmount": 0.6,
  "light": "zakat", "lightAmount": 0.8, "grade": "kino", "gradeAmount": 0.4,
  "fx": { "amount": 1, "wind": 0.2, "bloom": 0.3, "rays": 0.4, "flare": 0, "grain": 0.1, "vign": 0.2, "ca": 0, "bars": 0 },
  "lookBase": "metel" }
```

- `look` есть, только если образ выбран и не тронут. Если слои поменяли, вместо него `lookBase` (только для подписи «изменён», движок его не читает).
- `filter2` + `mix`: смесь двух стилей (доля второго). Новое поле, движок v2 его уже понимает (`Filtry.apply`).
- Выключенный слой пишется как `"none"`, поэтому состояние всегда полное и не зависит от того, что было до него.

| Метод | Что делает |
|---|---|
| `pult.get()` | состояние для записи в отрезок |
| `pult.event(at)` | `{ at, ...состояние, fade }` для списка `events` отрезка (`at` в секундах, минус = от конца) |
| `pult.set(state, fade?)` | показать на пульте и применить к видео. Понимает и короткие старые записи: `{look:'metel'}`, `{atmos:'sneg'}`. С `keep: true` добавляет к текущему, без него начинает с чистого |
| `pult.reset()` | чистое видео |
| `pult.sunAt(x, y)` | солнце и центр эффектов (0..1, ноль снизу), например по клику на кадре |
| `pult.tab(name)` | вкладка: `looks, style, atmos, light, grade, film` |
| `pult.fade`, `pult.trans` | длительность и вид смены облика (то же на вкладке «Плёнка») |
| `pult.destroy()` | убрать блок |

## Как это ложится на редактор

- Выбрали отрезок: `pult.set(seg)`. Изменили на пульте: в `onChange` записать `state` в отрезок.
- «Событие здесь»: `seg.events.push(pult.event(video.currentTime - seg.in))`. Выбрали событие: `pult.set(ev)`.
- Перемотка внутри отрезка: собрать облик на момент времени (отрезок, затем события с `at` ≤ t по порядку, с `keep: true`) и вызвать `pult.set(...)`.
- Движок при проигрывании применяет те же поля через `F.apply(e, fade)`, так что в редакторе и в плеере картинка одна.
